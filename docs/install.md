# Install LibreRead

Requires Android 8.0 or newer. The app is named **LibreRead**, package `net.aspectstudio.libreread`.

1. Open [the latest release](https://github.com/jschof1/libreread/releases/latest).
2. Download the Android APK and open it on your phone.
3. If Android asks, allow installation from your browser or download app.
4. Open **Settings → LibreRead reader**.
5. Enter your compatible article service's HTTPS URL and device credential.
6. Find a video and acknowledge AI processing when you want to generate its article.

The public APK contains no service credential or provider key. It does not include a free hosted AI account. Run [the included backend](../backend/README.md) or obtain access to a compatible service. A provider API key is not a device credential.

The article menu offers original transcript, rewrite, style, length, text size and reading width. Saved articles reopen offline.

If you installed LibreRead Debug, keep it if you need its saved reading. The release installs separately and does not migrate that data. Saved reading is excluded from Android backup and is lost on uninstall or device loss.

Use LibreTube's import flow for subscriptions. Google login and the exact personalised YouTube Home feed are unavailable.
