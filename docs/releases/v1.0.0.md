# LibreRead 1.0.0

Read YouTube as detailed articles with original transcripts, configurable writing style and offline saved reading. Video and audio playback are disabled.

## Install and configure

Requires Android 8.0 or newer. Download `LibreRead-1.0.0-android.apk`, open it and allow installation from that source if Android asks.

The public APK contains no service URL, credential or provider key. Configure a compatible HTTPS article service and device credential in **Settings → LibreRead reader**. Run the included backend or obtain access to a compatible service. A hosted AI account is not included.

The app is named **LibreRead**, package `net.aspectstudio.libreread`. It installs separately from LibreRead Debug; keep the debug installation if you need its saved reading.

## Included

- LibreTube browsing, search, local subscriptions and imports.
- Detailed articles with separate style and length controls.
- Original transcripts and source labels, including labelled AI transcription when captions are unavailable.
- Offline articles, restored position, adjustable text size and reading width.
- Recoverable generation errors and rewrites that preserve the old article on failure.
- A signed, optimized and non-debuggable Android release.

`SHA256SUMS` identifies the APK. Release metadata records its package, version, signature and non-debuggable flag.

## Limits

Google login and the exact personalised YouTube Home feed are unavailable. AI output can contain errors, and restricted or oversized videos may not convert. Saved reading is excluded from Android backup and is lost on uninstall or device loss.
