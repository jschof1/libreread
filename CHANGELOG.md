# Changelog

## 1.0.0

- Open video selections as detailed articles, with playback disabled.
- Keep the original transcript and source provenance alongside the article.
- Choose writing style, length and custom instructions separately.
- Save articles offline and restore reading position.
- Recover from failed requests and preserve the old article when a rewrite fails.
- Deliver a signed, non-debuggable release with the LibreRead name and version.
- Keep provider keys on the server and personal access credentials out of source.

The first release retains LibreTube's local subscriptions and import model. Google login and the personalised YouTube Home feed are not included.
